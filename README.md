# Cyber Threat Landscape Brief

A beginner-friendly awareness project explaining five common cyber threats in plain language, using trusted public sources.

## Contents

| File | Description |
|------|-------------|
| `Cyber_Threat_Brief.pdf` | Two-page brief: what each threat is, a sourced real-world example, and a simple defence |
| `Awareness_Poster.pdf` | One-page A4 poster linking each threat to one simple habit |
| `Sources.pdf` | Full list of sources (also printed on page 2 of the brief) |

## The five threats covered

1. **Phishing and social engineering** - fake messages, texts and calls that trick people into sharing details
2. **Weak, reused and stolen passwords** - and why multi-factor authentication (MFA) helps
3. **Ransomware** - malicious software that locks files and demands payment
4. **Malware from fake or unofficial apps** - harmful software hidden in "free" downloads
5. **Unpatched software** - known flaws left open because updates were postponed

## Sources used

Primary sources were preferred: Verizon 2026 Data Breach Investigations Report, FBI Internet Crime Complaint Center (IC3) 2025 report, CISA guidance and Known Exploited Vulnerabilities catalogue, and NIST SP 800-63B. Nepal examples come from Nepal Police Cyber Bureau and National Cyber Security Centre notices as reported in public news. Where only a news or industry summary was available, it is marked as secondary in the source list.

## Approach and safety notes

- Written to inform without scaring readers.
- No instructions for carrying out attacks are included.
- Real organisations appear only where the event is documented in public sources (for example, the 2021 Colonial Pipeline incident in CISA/FBI advisories).
- Statistics describe the reporting years named; figures from different reports are not directly comparable.
